## قواعد النشر والتحقق
1. لا يُنشر ادعاء هندسي أو نظامي أو رقم سوقي قبل تحديد مصدره الأولي وإصداره/تاريخه والفقرة أو الجدول ذي الصلة.
2. تُفصل الحقيقة الموثقة عن التحليل والرأي والتقدير والبيانات غير المتحققة.
3. لا تعني عبارة «الملف موجود» أو «المحتوى مكتوب» أنه صالح للنشر.
4. في المسائل الهندسية، تكون المخططات والمواصفات والعقد المعتمد وأكواد البناء السعودية ذات الصلة هي المرجع بحسب نطاق كل ادعاء.
5. لا تُستخدم أرقام أو مدد أو معاملات عامة بوصفها قاعدة مطلقة إذا كانت تتغير بحسب المشروع أو المادة أو العقد.
6. لا يُقدّم المحتوى التعليمي بديلاً عن التصميم أو الفحص أو الاعتماد المهني للمشروع الفعلي.

## حالة المراجعة
الفحص الهيكلي للفهرس لا يساوي تدقيقاً علمياً. ملفات المحتوى تمر بمراحل منفصلة: **مسودة → مراجعة فنية/نظامية → تحقق مصدر → مراجعة تحريرية → اعتماد نشر**. أي ملف لم يوثق اجتيازه لهذه المراحل يبقى غير معتمد.
