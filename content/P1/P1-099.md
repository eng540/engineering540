# تنسيق السباكة والتكييف مع الإنشائي: كيف تتجنب فتحات غير معتمدة في الكمرات؟

**سكربت فيديو — المدة المستهدفة 80 ثانية.**

**[0–5 ث] (لقطة لفتحة غير معتمدة في كمرة):**  
«إذا اصطدم مسار خدمة بكمرة، لا تبدأ بالتكسير. ابدأ بمراجعة المخططات ورفع التعارض للمصمم.»

**[5–13 ث] (لقطة على مخطط إنشائي ومخطط سباكة):**  
«لا تُحدث فتحة أو تخريماً في كمرة أو عمود أو بلاطة إنشائية دون مراجعة المصمم الإنشائي واعتماد تفصيل مناسب. وقد يكون الحل بتعديل مسار الخدمة أو بتصميم فتحة إذا سمح التحليل.»

**[13–24 ث] (لقطة قياس الكمرة ومنسوب السقف):**  
«راجع عمق الكمرة ومنسوبها الفعليين والارتفاع الصافي المطلوب. لا تستخدم عمقاً افتراضياً لكل الكمرات؛ اقرأ القطاع والتفاصيل وقارنها بمناسيب السقف المستعار.»

**[24–34 ث] (لقطة لمسار مجرى هواء أسفل كمرة):**  
«في الدكت، راجع الأبعاد الخارجية والعزل والتعليق والخلوص ومساحة الصيانة، وليس مقاس المجرى الداخلي فقط. التنسيق يجب أن يحافظ على الارتفاعات الصافية ومتطلبات التشغيل.»

**[34–44 ث] (لقطة لماسورة صرف مع جهاز قياس منسوب):**  
«الصرف يحتاج ميلاً ومناسيب يحددها التصميم حسب قطر الأنبوب ونوع النظام. إذا تعارض المسار مع الكمرة، ادرس إعادة المسار أو ارفع استفساراً؛ لا تنفذ فتحة دون تفصيل معتمد يحدد الموقع والأبعاد والتسليح والتقوية.»

**[44–56 ث] (لقطة سجل تعارضات):**  
«سجّل التعارض برقم وموقع واللوحات المعنية والتخصصات والمسؤول عن الحل وتاريخ الإغلاق. اعتمد الحل كتابةً قبل التنفيذ.»

**[56–68 ث] (لقطة تنسيق قبل صب السقف):**  
«التنسيق الأفضل يتم قبل الصب. بعد الصب قد تتوفر بدائل، لكنها تحتاج تقييماً وتصميماً وقد تكون أكثر تعقيداً أو كلفة؛ لا تلمس العنصر الحامل دون موافقة المصمم.»

**[68–80 ث] (لقطة ختامية للمهندس أمام المخطط):**  
«الخلاصة: غيّر مسار الخدمة قبل أن تغيّر الكمرة. احفظ الفيديو وشاركه مع فريق الموقع قبل صب السقف.»
