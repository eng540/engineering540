# 09 — نظام المراجعة والتحقق التحريري

**المخرج الذي تغطيه:** (9) نظام مراجعة وتحقق.
**الفلسفة:** المصداقية هي أصل المنصة الوحيد الذي لا يُشترى — كل قاعدة في هذه الوثيقة تحميه. النظام مصمم لشخص واحد: قوائم فحص قصيرة، عتبات واضحة، وأتمتة ما يمكن.

---

## 1) مبادئ النظام الخمسة

1. **كل رقم له مصدر وتاريخ** — أو لا يُنشر (يُقدَّم كـ«تقدير توضيحي» بوسم صريح).
2. **فصل إلزامي بين ثلاث فئات:** حقيقة موثقة / رأي وتحليل / تقدير ومثال — بوسوم ظاهرة للقارئ لا مخفية في الداخل.
3. **الأنظمة والمال من المصادر الرسمية السعودية** (MOMRAH، الهيئة العامة للعقار/فال، GASTAT، ZATCA، هيئة المهندسين، الهيئة الملكية لمكة…) — والتاريخ مكتوب.
4. **لا نسخ بلا إضافة قيمة** — أي اقتباس يُنسب لمصدره ويضاف إليه زاوية أو تطبيق أو تحليل.
5. **التصحيح علني وسريع** — خطأ مكتشف يُصحح خلال 24 ساعة في نفس المنشور بعبارة «تصحيح:» لا بحذف صامت.

## 2) خط الإنتاج التحريري (7 مراحل)

```
① فكرة (من قاعدة الموضوعات) → ② مسودة (بقالب السلسلة + مساعدة AI)
→ ③ تحقق فني → ④ تحقق مصدرية/نظامية → ⑤ تنقيح لغوي وهويّة
→ ⑥ توقيع ونشر → ⑦ أرشفة وتسجيل
```

| المرحلة | الفعل | الوقت | أداة الفحص |
|---|---|---|---|
| ① فكرة | اختيار من القاعدة + تحديد السلسلة والمنتجات المشتقة | 10 د | قاعدة الموضوعات |
| ② مسودة | كتابة بالقالب؛ AI يساعد بالهيكلة لا بالمعلومات | 45–60 د | قوالب الأوامر (وثيقة 12) |
| ③ تحقق فني | فحص كل ادعاء فني بمرجعه | 15–20 د | قائمة الفحص الفني (§4) |
| ④ تحقق مصدرية | فحص الأرقام/الأنظمة بمصادرها الرسمية + تاريخ | 15–20 د | قائمة المصدرية (§5) |
| ⑤ تنقيح | لغة، عناوين، وسوم، توقيع، بلا مبالغة | 10–15 د | قائمة الصياغة (§6) |
| ⑥ نشر | نشر بجدوله + تفاعل أول ساعة | — | تقويم النشر |
| ⑦ أرشفة | تسمية معيارية + تحديث سجل التحقق + تسجيل الأداء لاحقاً | 5 د | سجل التحقق (§8) |

**إجمالي عبء المراجعة:** ~40–55 دقيقة للأصل الطويل — تقع ضمن زمن الإنتاج المقدر (75–90 د) لا فوقه، لأن المسودة تُكتب بمصادرها من البداية.

## 3) وسوم التحقق الإلزامية (تظهر في المنشور)

| الوسم | متى يُستخدم | صيغة النشر |
|---|---|---|
| **[حقيقة]** | ادعاء فني/نظامي/إحصائي موثق | `[حقيقة — المصدر: … — بتاريخ: …]` |
| **[رأي/تحليل]** | قراءة وتقدير يحمل صوت المؤسس | `[تحليل — عبدالمجيد الفقيه]` |
| **[تقدير توضيحي]** | أرقام مثال/نموذج غير موثقة من السوق الحي | `[أرقام توضيحية للتقريب — ليست أسعاراً معتمدة]` |
| **[لم يتحقق]** | معلومة منتشرة لم نجد مصدرها الرسمي | `[معلومة منتشرة — لم تتحقق من مصدر رسمي]` |

**قاعدة العنوان:** العنوان لا يقول أبداً ما لا تقوله الصفحة؛ الأسئلة تُصاغ كأسئلة لا كحقائق؛ لا «ثورة» ولا «سرّ» ولا وعود عائد.

## 4) قائمة الفحص الفني (قابلة للطباعة)

- [ ] كل خطوة/نقطة فحص مذكورة تقابل ممارسة معتمدة (كود/مواصفة/دليل بلدي أو سلوك مهني راسخ).
- [ ] الأكواد والمواصفات مذكورة باسمها العام (SBC، المواصفات العامة، ACI…) دون أرقام إصدار غير متحقق منها.
- [ ] المثال الرقمي (كميات/تكاليف) متسق داخلياً وموسوم [تقدير توضيحي].
- [ ] لا توصية تتجاوز حدود دور المهندس (لا تصميم بلا مسئولية تصميم، لا فتوى نظامية).
- [ ] الحالة الحرجة (متى توقف العمل وتستشير متخصصاً) مذكورة إن وجدت.
- [ ] المصطلح العربي يليه الإنجليزي بين قوسين عند أول ذكر.

## 5) قائمة الفحص المصدري والنظامي

- [ ] كل رقم سوقي/إحصائي له: مصدر مسمى + رابط (يُحفظ في سجل التحقق) + تاريخ.
- [ ] المعلومة النظامية من مصدر رسمي سعودي، ومصوغة «وفق/حسب» لا «النظام يقول» إن كان فهمنا اجتهادياً.
- [ ] الأرقام السوقية من مصادر ثانوية (تقارير) مذكورة كذلك وبتاريخ النشر.
- [ ] لا وعود استثمارية ولا نسب عائد مؤكدة — العوائد تُعرض كحسابات توضيحية بحساسيتها.
- [ ] أي إعلان/تغيير نظامي لم يُنشَر رسمياً لا يدخل المحتوى إلا بوسم [لم يتحقق] أو يُترك.
- [ ] معلومات مكة: تمييز صريح بين «معلن رسمياً» و«قراءة تحليلية» (ضوابط سلسلة مكة تبني — وثيقة 14).

## 6) قائمة الفحص اللغوي والهويّة

- [ ] العنوان محدد وصادق (يخضع قواعد §3) ومطابق لمعيار السلسلة.
- [ ] النبرة: مهنية مباشرة — لا مبالغة، لا تهوين، لا خطابة.
- [ ] البنية: هوك ← جسد ← خلاصة عملية ← CTA واحد ← توقيع مناسب.
- [ ] التوقيع الصحيح حسب نوع الصوت (منصوي/تحليلي/مهني — وثيقة 02 §1.6).
- [ ] وسوم التحقق ظاهرة في موضعها، والتاريخ مذكور.
- [ ] صياغة عربية سليمة ومصطلحات موحدة (معجم مصطلحات قصير يُحدّث تدريجياً في أرشيف المنصة).

## 7) عتبات الحظر (يُوقف النشر فوراً إن تحقق أي شرط)

1. رقم أو نظام بلا مصدر يمكن التحقق منه.
2. وعد استثماري أو استشارة قانونية حاسمة.
3. عنوان مضلل أو مستفز بالكذب.
4. محتوى منسوخ دون إسناد وإضافة قيمة.
5. اختلاق تجربة/أعمال تُنسب للمؤسس لم تُنفذ.
6. معلومة تجرح جهة/شخصاً بلا إثبات موثق.

## 8) سجل التحقق والأرشفة

- **قالب سجل التحقق:** `templates/verification_log.csv` — أعمدته: تاريخ النشر · عنوان المنتج · السلسلة · المنتجات المشتقة · المصادر (روابط) · تاريخ التحقق · ملاحظات/تصحيحات.
- **الأرشفة:** كل منتج يُحفظ باسم معياري (وثيقة 12) + نسخة نصية من كل منشور (ملف نصي) — يبني أرشيفاً قابلاً للتجميع والبحث.
- **التصحيح بعد النشر:** منشور متابعة في نفس الخيط بعبارة «تصحيح وتوضيح:» + تعديل النص الأصلي إن أمكن + تسجيل الحادثة في السجل — ثم «درس أسبوعي» داخلي: أي قاعدة سمحت بالخطأ؟

## 9) آلية التوسع (عند انتقال الإنتاج لأكثر من شخص)

| الدور | المسؤولية | متى يُستحدث |
|---|---|---|
| المحرر (المؤسس حالياً) | فكرة + مسودة + قرار نشر | الآن |
| مدقق مصادر | الفحص ③④ فقط، لا يعدل الرأي | عند أول مساعد |
| مصمم/مونتير | تنفيذ المنتجات المشتقة من قوالب | عند ثبات الحجم |
| مراجع خارجي (استشاري/مهندس أكبر) | مراجعة المواضيع الحساسة (أنظمة/مال) | حسب الحاجة لكل موضوع |

**قاعدة النظام لشخص واحد:** مراجعة ذاتية منفصلة زمنياً — اكتب المسودة صباحاً، وراجعها عصراً بقائمتين ③ و④ كأنك مدقق مستقل؛ الفصل الزمني يعوّض غياب الشخص الثاني.
