# وكيل الإنتاج البصري — AI Visual Agent

> وكيل ذكاء اصطناعي يتولّى دورة إنتاج المنشور البصري كاملة لقناة «إبداعات هندسية»، من الموضوع إلى ملف PNG جاهز للنشر — بلا تدخّل يدوي.

**الملف التنفيذي:** `_raw/ai_visual_agent.py`

---

## 1) ما الذي يفعله الوكيل

```
موضوع من القاعدة (614)
        ↓
① قراءة وتحليل        — يستخرج العنوان، الجملة المفتاحية، والشرائح/الأقسام (6–10)
        ↓
② تخطيط فني           — يصوغ موجزاً بصرياً بحسب المحور ونوع المحتوى
        ↓
③ توليد الصورة        — يستدعي نموذج توليد صور (ثلاثة مزوّدين بترتيب الأولوية)
        ↓
④ تركيب عربي          — طبقة نصية احترافية بمقاس 1080×1350 (إن لزم)
        ↓
⑤ مراجعة جودة         — كلمات ممنوعة · رقم بلا مصدر · المقاس · الخط
        ↓
منشور PNG جاهز
```

---

## 2) المزوّدون (مرتّبون بحسب جودة النص العربي داخل الصورة)

| # | المزوّد | النموذج | يرسم العربية؟ | الناتج |
|---|---|---|---|---|
| 1 | `openrouter` | `google/gemini-3-pro-image` | ✔ نعم | بوستر كامل بالنص العربي من النموذج نفسه |
| 2 | `google` | `gemini-3-pro-image` | ✔ نعم | بوستر كامل بالنص العربي |
| 3 | `fal` | `fal-ai/flux-pro/v1.1-ultra` | ✘ لا | صورة بصرية + طبقة نص عربي من الوكيل |

**لماذا هذا الترتيب؟** نماذج Gemini للصور تكتب النص العربي داخل الصورة بجودة تصميمية حقيقية (تخطيط، تسلسل بصري، أيقونات). أما FLUX فلا يكتب العربية بشكل موثوق، فيُستخدم للصورة البصرية فقط ثم يُضاف النص بطبقة منفصلة منضبطة.

## 3) الأوامر

```bash
# 1) فحص حالة المزوّدين (يطلب صورة صغيرة حقيقية من كل واحد)
python _raw/ai_visual_agent.py --check

# 2) إنتاج منشور لموضوع واحد
python _raw/ai_visual_agent.py --topic P1-002

# 3) إنتاج من خطة اليوم (أول N موضوعاً غير مكرر)
python _raw/ai_visual_agent.py --batch plan --limit 3

# 4) فرض مزوّد معيّن
python _raw/ai_visual_agent.py --topic P3-051 --provider fal

# 5) تحديد مجلد الإخراج
python _raw/ai_visual_agent.py --topic P1-001 --out assets/
```

**الإخراج:** `assets/<رقم_الموضوع>.png` بمقاس 1080×1350.

## 5) حالة المزوّدين (آخر فحص: 2026-11-08 22:09)

| المزوّد | الحالة | السبب الفعلي |
|---|---|---|
| `openrouter` | 🔴 متوقّف | `HTTP 402` — يتطلب رصيداً ≥ 1.00$ لمخرجات الصور |
| `google` | 🔴 متوقّف | `HTTP 429` — `RESOURCE_EXHAUSTED` نفدت الحصة المجانية |
| `fal` | 🔴 متوقّف | `HTTP 403` — `User is locked. Reason: TOP_UP` |

**الأثر:** الوكيل يعمل ويُنتج ملفات، لكن **بخلفية بديلة لا صورة مولّدة**، ويسجّل تنبيهاً صريحاً في المراجعة: «لم تُستخدم صورة مولّدة — خلفية بديلة».

### كيف يُفتح كل مزوّد

| المزوّد | الإجراء | التكلفة التقديرية |
|---|---|---|
| **OpenRouter** *(الأنسب)* | تعبئة رصيد في `openrouter.ai/credits` | **1$ حد أدنى** — يفتح Gemini 3 Pro Image |
| Google AI Studio | تفعيل الفوترة في المشروع، أو انتظار تجدّد الحصة اليومية | حسب الاستخدام |
| fal.ai | تعبئة رصيد في `fal.ai/dashboard/billing` | حسب الاستخدام |

بعد فتح أي مزوّد: شغّل `--check` للتأكد، ثم `--batch plan --limit 5` للإنتاج الفعلي.

## 6) ضوابط الوكيل (غير قابلة للتجاوز)

1. **لا وعود مالية** — يرفض الكلمات: مضمون، ربح مضمون، استثمار آمن، سوف يرتفع، عائد مضمون، فرصة ذهبية.
2. **كل رقم يحتاج مصدراً** — إن وُجد رقم بلا مصدر معلن، يسجّل ملاحظة في تقرير المراجعة.
3. **لا وجوه بشرية ولا صور فوتوغرافية** في الموجز الفني — التزاماً بهوية القناة.
4. **لا اختراع نصوص** — العنوان والجملة المفتاحية يُنقلان حرفياً من ملف المحتوى.
5. **المقاس ثابت** 1080×1350 (4:5) — الأفضل ظهوراً في تغذية انستغرام.
6. **إفصاح صريح** — عند تعذّر التوليد، يُعلن الوكيل ذلك ولا يوهم بنتيجة مولّدة.

## 7) البنية الداخلية

| الوحدة | الوظيفة |
|---|---|
| `load_keys()` | قراءة المفاتيح من ملف الاعتماد |
| `check_providers()` | فحص فعلي بطلب حقيقي لكل مزوّد |
| `read_topic() / parse_topic()` | استخراج العنوان والمفتاح والشرائح (يدعم «الشريحة N» وأقسام `##`) |
| `art_brief()` | الموجز الفني الكامل للمزوّدات التي ترسم العربية |
| `compose_prompt_flux()` | موجز بصري بلا نص لمزوّدات FLUX |
| `compose()` | تركيب الطبقة النصية العربية (ستارة، تسلسل، هوية، تذييل) |
| `qc_check()` | مراجعة الجودة والالتزام |
| `produce()` | تنسيق الدورة الكاملة لموضوع واحد |
