## الملخص التنفيذي (اقرأ هذا أولاً)

القناة اليوم قناة معلومات هندسية عامة تعتمد على نقل وتجميع. هذه المنظومة تحوّلها إلى **منصة معرفة هندسية وعقارية سعودية** بثلاث ركائز:

1. **إنتاج أصلي موثق** — لا إعادة نشر: 614 موضوعاً جاهزاً بمصادرها ووسوم تحققها، و19 سلسلة تحريرية بإيقاع أسبوعي، ونظام مراجعة يمنع نشر أي رقم دون (مصدر + تاريخ + رابط).
2. **منتج واحد يتشتت** — منطق 1←6: موضوع واحد يخرج مقالاً في تيليجرام، كاروسيل في انستغرام، فيديو 60 ثانية، خيط X، قصص سناب، ومقال فيسبوك — بميزانية وقت 12–20 ساعة أسبوعياً لمشغّل فردي.
3. **مسار تجاري أخلاقي** — قمع من جمهور إلى إشارات اهتمام إلى عروض محدودة الحدود (قوالب مسعّرة، جلسات مراجعة، مرافقة قرار) — بلا وعود استثمارية ولا وساطة غير مرخصة.

**ما يميز الوضع الممكن:** قاعدة بيانات مكة الجاهزة (1,859 مكتباً هندسياً بالسجل الرسمي، 381 منها بالمدينة، 228 مصدراً) + معطيات مكة الموثقة بتاريخها (حج 1447 = 1,707,301 حاجاً رسمياً؛ منافسة تطوير مخطط منح ولي العهد 9-ط؛ برنامج الأحياء المطورة ومنصة مُتم) — أصالة محتوى لا يستطيع منافس تقليدها بنقل الأخبار.
