# منظومة محتوى إبداعات هندسية (Engineering 540)

نقل منظم لمنظومة المحتوى التي بُنيت داخل محادثة Gemini المشاركة (https://share.gemini.google/apilYvmpNsml، من 8 نوفمبر 2026). النقل تنظيمي: المحتوى منقول كما ورد في المحادثة ولم يُتحقق من ادعاءاته الهندسية والنظامية فرداً فرداً.

## الهيكل

| المسار | المحتوى |
|---|---|
| `docs/governance/` | الدستوران: `ENG540-CONTENT-STANDARD-001` (المحتوى) و`ENG540-DESIGN-GOVERNANCE-002` (التصميم)، مع سياق التعديلات |
| `docs/strategy/content-strategy-document.md` | وثيقة الاستراتيجية الكاملة: المحاور، المنصات، السلاسل، خطة 90 يوماً، جدول الموضوعات الخام |
| `docs/produced-content/` | دفعة الحلقات الميدانية الجديدة المنتجة في المحادثة |
| `skills/eng540-content-studio/` | ثلاث نسخ من وصف مهارة الإنتاج كما ظهرت في المحادثة |
| `templates/` | `ai_visual_agent.py` (v2.0)، `carousel.html` (v2.0)، `video-studio-v2.html`، `eng540-studio-v3.html` |
| `topics/` | 312 موضوعاً: ملف لكل موضوع داخل مجلد محوره، و`topics.csv` و`topics.json` و`INDEX.md` |

## متتبع النشر

الحالات: **فكرة** (لا نص بعد)، **مسودة**، **مراجع**، **منشور**. لكل موضوع في `topics.csv` الأعمدة `status` و`published_platform` و`published_date` و`published_link`. كل المواضيع الآن `فكرة` عدا خمسة لها نص مطوّر في المحادثة (`مسودة`). لم تُسجَّل أي حالة نشر لأن المحادثة لا تحمل تواريخ أو روابط نشر موثقة.

## وسم الرصانة

يلتزم المحتوى المستقبلي بوسوم الدستورين: **حقيقة رسمية** / **تحليل هندسي** / **تقدير توضيحي**، مع رابط مصدر لأي ادعاء نظامي قبل النشر. انظر `docs/governance/`.

راجع `TRANSFER_NOTES.md` للفجوات وما استُبعد عمداً.
