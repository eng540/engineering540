# E540-010: متى نختار اللبشة المسلحة (Raft Foundation) بدلاً من القواعد المنفصلة في المباني السكنية والتجارية؟

**الوصف المختصر:** هدر المال في لبشة غير لازمة أو المخاطرة بقواعد منفصلة متداخلة على تربة ضعيفة

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الأول: الهندسة المدنية والتطبيق العملي |
| التصنيف الفرعي | الأساسات والقواعد والأعمدة والأسقف |
| الجمهور المستهدف | المهندسون الإنشائيون، المطورون، الملاك |
| المشكلة أو السؤال | هدر المال في لبشة غير لازمة أو المخاطرة بقواعد منفصلة متداخلة على تربة ضعيفة |
| القيمة التعليمية أو التجارية | اتخاذ قرار هندسي واقتصادي سليم يوازن بين الأمان الإنشائي والتكلفة |
| زاوية المعالجة | معادلة المساحة (تجاوز القواعد 60% من مسطح المبنى) ودراسة حالة بالأرقام |
| نوع المحتوى | دراسة حالة + منشور تحليلي |
| المنصة المناسبة | Telegram + X + Facebook |
| المصادر المطلوبة | المركز السعودي لكود البناء (https://sbc.gov.sa/) |

| إمكانية تحويله إلى سلسلة | سلسلة: هندسة بالأرقام |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | خدمة الهندسة القيمية ومراجعة التصميم الإنشائي |
