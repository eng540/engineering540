# E540-025: كيف تبني خطة ضبط جودة (Project Quality Plan) مبسطة وفعالة لمشاريع الفلل والعمائر السكنية؟

**الوصف المختصر:** غياب منهجية واضحة للفحص والاعتماد في المشاريع الصغيرة والمتوسطة

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الأول: الهندسة المدنية والتطبيق العملي |
| التصنيف الفرعي | ضبط الجودة QA/QC |
| الجمهور المستهدف | مهندسو الجودة، مديرو المشاريع، المكاتب الاستشارية |
| المشكلة أو السؤال | غياب منهجية واضحة للفحص والاعتماد في المشاريع الصغيرة والمتوسطة |
| القيمة التعليمية أو التجارية | تحويل العمل من الفوضى والاجتهاد الشخصي إلى نماذج استلام قياسية موثقة |
| زاوية المعالجة | هيكل خطة الجودة: اعتماد المواد (MIR)، طلبات الفحص (WIR)، وتقارير عدم المطابقة (NCR) |
| نوع المحتوى | ملف PDF + قالب Word/Excel |
| المنصة المناسبة | Telegram + Facebook |
| المصادر المطلوبة | الأدلة الاسترشادية لكود البناء - الهيئة السعودية للمهندسين (https://www.saudieng.sa/Arabic/RegulationsAndProcedures/Pages/SBCGuidelines.aspx) |
| درجة الأولوية | عالية |
| إمكانية تحويله إلى سلسلة | سلسلة: المقاول الذكي |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | تصميم أنظمة ونماذج QA/QC لشركات المقاولات والمكاتب |

## المحتوى

لم يُطوَّر نص هذا الموضوع في المحادثة. المتاح هو بيانات الجدول أعلاه فقط.
