# E540-078: مراقبة التكاليف أثناء التنفيذ (Cost Control): كيف تقارن الميزانية التقديرية بالتكلفة الفعلية أسبوعياً؟

**الوصف المختصر:** اكتشاف الخسارة أو تجاوز الميزانية بعد انتهاء المشروع وفوات الأوان

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)
