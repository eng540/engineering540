# E540-085: جدولة توريد المواد الطويلة الأجل (Long-Lead Items): المصاعد، التكييف المركزي، والواجهات

**الوصف المختصر:** تأخر تسليم المشروع لعدة أشهر بعد انتهاء التشطيب بسبب تأخر طلب المصعد أو وحدات التكييف

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثاني: المقاولات وإدارة المشاريع |
| التصنيف الفرعي | العمالة والمعدات والمواد |
| الجمهور المستهدف | مديرو المشاريع، المطورون، الملاك |
| المشكلة أو السؤال | تأخر تسليم المشروع لعدة أشهر بعد انتهاء التشطيب بسبب تأخر طلب المصعد أو وحدات التكييف |
| القيمة التعليمية أو التجارية | تحديد المواد التي تحتاج تصنيعاً أو استيراداً وطلبها في الوقت المناسب ضمن المسار الحرج |
| زاوية المعالجة | جدول زمني لمواعيد التعاقد على البنود الخاصة منذ مرحلة العظم |
| نوع المحتوى | إنفوجرافيك + مقال |
| المنصة المناسبة | Instagram + Telegram + X |
| المصادر المطلوبة | الهيئة السعودية للمقاولين - العقود النموذجية ومؤشرات الأسعار (https://sca.sa/ar/pages/missions) |
| درجة الأولوية | عالية |
| إمكانية تحويله إلى سلسلة | سلسلة: افهم مشروعك |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | خدمة التخطيط والجدولة الزمنية للمشاريع (Planning) |

## المحتوى

لم يُطوَّر نص هذا الموضوع في المحادثة. المتاح هو بيانات الجدول أعلاه فقط.
