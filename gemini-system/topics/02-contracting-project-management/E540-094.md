# E540-094: الفرق بين عقود المقطوعية (Lump Sum) وعقود إعادة القياس (Re-measured / Unit Rate) وعقود التكلفة زائد نسبة (Cost Plus)

**الوصف المختصر:** اختيار نوع عقد لا يناسب درجة اكتمال المخططات (مثل عقد مقطوعية لمخطط ناقص)

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)
