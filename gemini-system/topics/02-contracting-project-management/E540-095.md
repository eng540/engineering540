# E540-095: سجل المخاطر (Risk Register) في مشاريع المقاولات: كيف تتوقع العوائق قبل وقوعها وتضع خطط الطوارئ؟

**الوصف المختصر:** إدارة المشاريع بردود الأفعال اليومية والارتباك عند أول أزمة في الموقع

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثاني: المقاولات وإدارة المشاريع |
| التصنيف الفرعي | إدارة المخاطر |
| الجمهور المستهدف | مديرو المشاريع، المقاولون، المطورون |
| المشكلة أو السؤال | إدارة المشاريع بردود الأفعال اليومية والارتباك عند أول أزمة في الموقع |
| القيمة التعليمية أو التجارية | بناء مصفوفة مخاطر عملية (احتمالية الحدوث × شدة الأثر) لأهم 15 خطراً في مشاريع البناء |
| زاوية المعالجة | شرح تطبيقي لمخاطر التربة، السيولة، سلاسل الإمداد، والعمالة مع قالب جاهز |
| نوع المحتوى | قالب Excel + مقال |
| المنصة المناسبة | Telegram + X |
| المصادر المطلوبة | الهيئة السعودية للمقاولين - العقود النموذجية ومؤشرات الأسعار (https://sca.sa/ar/pages/missions) |
| درجة الأولوية | عالية |
| إمكانية تحويله إلى سلسلة | سلسلة: المقاول الذكي |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | قالب سجل المخاطر وخطط الاستجابة للمشاريع |
