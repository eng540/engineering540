# E540-119: شراكة مالك الأرض والمطور العقاري: كيف تُقيّم حصة الأرض مقابل حصة البناء والتطوير بعدالة؟

**الوصف المختصر:** امتلاك أراضٍ مميزة دون سيولة للبناء، أو امتلاك خبرة وسيولة دون أرض

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | مبادئ التطوير العقاري ودورة حياة المشروع |
| الجمهور المستهدف | ملاك الأراضي، المطورون العقاريون، المستثمرون |
| المشكلة أو السؤال | امتلاك أراضٍ مميزة دون سيولة للبناء، أو امتلاك خبرة وسيولة دون أرض |
| القيمة التعليمية أو التجارية | هيكلة شراكة تطوير عقاري (أرض من طرف + تطوير وتمويل من طرف) وتحديد النسب وفق التدفقات |
| زاوية المعالجة | 3 نماذج عملية لهيكلة الشراكة بين مالك الأرض والمطور مع مثال رقمي |
| نوع المحتوى | قالب Excel + مقال تحليلي |
| المنصة المناسبة | Telegram + X |
| المصادر المطلوبة | نظام المساهمات العقارية - الهيئة العامة للعقار (https://rega.gov.sa/rega-services/platforms/real-estate-contributions/) |
| درجة الأولوية | عالية جداً |
| إمكانية تحويله إلى سلسلة | سلسلة: فرصة في السوق |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | خدمة التوفيق وهيكلة الشراكات بين ملاك الأراضي والمطورين |

## المحتوى

لم يُطوَّر نص هذا الموضوع في المحادثة. المتاح هو بيانات الجدول أعلاه فقط.
