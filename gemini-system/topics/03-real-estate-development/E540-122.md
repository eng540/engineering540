# E540-122: الفرق الجوهري بين الأرض المستوية والأرض الجبلية أو المنحدرة في تكلفة الأساسات والقبو (البدروم)

**الوصف المختصر:** إغفال تكلفة الجدران الاستنادية (Retaining Walls) والقطع الصخري عند مقارنة سعر متر الأرض

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | دراسة الأراضي والمخططات وتحليل المواقع |
| الجمهور المستهدف | ملاك الأراضي، المطورون، المهندسون |
| المشكلة أو السؤال | إغفال تكلفة الجدران الاستنادية (Retaining Walls) والقطع الصخري عند مقارنة سعر متر الأرض |
| القيمة التعليمية أو التجارية | حساب التكلفة الحقيقية للأرض شاملة تكلفة تهيئتها للبناء (Land Readiness Cost) |
| زاوية المعالجة | مقارنة بالأرقام بين أرض مستوية بسعر 1500 ريال/م2 وأرض جبلية بسعر 1100 ريال/م2 |
| نوع المحتوى | دراسة حالة بالأرقام + إنفوجرافيك |
| المنصة المناسبة | Telegram + Instagram + X |
| المصادر المطلوبة | المركز السعودي لكود البناء (https://sbc.gov.sa/) |
| درجة الأولوية | عالية جداً |
| إمكانية تحويله إلى سلسلة | سلسلة: هندسة بالأرقام |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | حاسبة التكلفة الفعلية للأرض بعد التمهيد والأساسات |

## المحتوى

لم يُطوَّر نص هذا الموضوع في المحادثة. المتاح هو بيانات الجدول أعلاه فقط.
