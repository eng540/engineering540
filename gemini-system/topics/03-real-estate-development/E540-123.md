# E540-123: قراءة الاشتراطات العمرانية ونظام البناء (معامل البناء FAR، نسبة التغطية، الارتدادات، الأدوار)

**الوصف المختصر:** شراء أرض تجارية أو سكنية دون حساب المسطحات البيعية الصافية المسموح ببنائها نظاماً

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | دراسة الأراضي والمخططات وتحليل المواقع |
| الجمهور المستهدف | المطورون، الملاك، المكاتب الهندسية، الوسطاء |
| المشكلة أو السؤال | شراء أرض تجارية أو سكنية دون حساب المسطحات البيعية الصافية المسموح ببنائها نظاماً |
| القيمة التعليمية أو التجارية | معادلة حساب أقصى مساحة بنائية وبيعية مسموحة لتقييم السعر العادل للمتر المربع من الأرض |
| زاوية المعالجة | شرح تطبيقي لحساب المسطحات والارتدادات والمواقف المطلوبة وفق اشتراطات وزارة البلديات |
| نوع المحتوى | مقال تعليمي + قالب Excel |
| المنصة المناسبة | Telegram + X |
| المصادر المطلوبة | اشتراطات إنشاء المباني السكنية - وزارة البلديات والإسكان (https://momah.gov.sa/sites/default/files/2024-07/ashtratat%20a%27nsha%20almbany%20alsknyt%20m%60%20alqrar.pdf) |
| درجة الأولوية | عالية جداً |
| إمكانية تحويله إلى سلسلة | سلسلة: مصطلح عقاري وهندسي |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | خدمة دراسة الطاقة الاستيعابية للأراضي الاستثمارية |

## المحتوى

لم يُطوَّر نص هذا الموضوع في المحادثة. المتاح هو بيانات الجدول أعلاه فقط.
