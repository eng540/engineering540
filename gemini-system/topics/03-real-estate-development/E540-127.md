# E540-127: كيف تعد دراسة جدوى أولية لمشروع تطوير عقاري (فلل أو شقق تمليك) في 60 دقيقة؟

**الوصف المختصر:** الدخول في مشاريع عقارية بناءً على تقليد المنافسين دون نموذج مالي يختبر الحساسية والمخاطر

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | تحليل العرض والطلب ودراسة الجدوى |
| الجمهور المستهدف | المطورون الناشئون، المستثمرون، المهندسون |
| المشكلة أو السؤال | الدخول في مشاريع عقارية بناءً على تقليد المنافسين دون نموذج مالي يختبر الحساسية والمخاطر |
| القيمة التعليمية أو التجارية | بناء نموذج مالي يحسب التكلفة الاستثمارية، الإيرادات المتوقعة، صافي الربح، والعائد على الاستثمار (ROI & IRR) |
| زاوية المعالجة | شرح عملي لمدخلات ومخرجات دراسة الجدوى مع قالب Excel تفاعلي جاهز |
| نوع المحتوى | قالب Excel + فيديو شرح |
| المنصة المناسبة | Telegram + YouTube/TikTok |
| المصادر المطلوبة | الهيئة العامة للعقار (https://rega.gov.sa/) |
| درجة الأولوية | عالية جداً |
| إمكانية تحويله إلى سلسلة | سلسلة: هندسة بالأرقام |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | بيع قالب دراسة الجدوى العقارية المتقدم + خدمة إعداد الدراسات |

لم يُطوَّر نص هذا الموضوع في المحادثة. المتاح هو بيانات الجدول أعلاه فقط.
