# E540-128: تحليل الحساسية (Sensitivity Analysis) في المشاريع العقارية: ماذا يحدث لربحك لو ارتفعت التكلفة 10% وتأخر البيع 6 أشهر؟

**الوصف المختصر:** بناء دراسة الجدوى على السيناريو المتفائل فقط والانهيار عند أول تغير في السوق أو التكلفة

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | تحليل العرض والطلب ودراسة الجدوى |
| الجمهور المستهدف | المطورون العقاريون، الممولون، المستثمرون |
| المشكلة أو السؤال | بناء دراسة الجدوى على السيناريو المتفائل فقط والانهيار عند أول تغير في السوق أو التكلفة |
| القيمة التعليمية أو التجارية | اختبار صمود المشروع أمام 3 سيناريوهات (متفائل، أساسي، متحفظ) وتحديد هامش الأمان |
| زاوية المعالجة | مصفوفة حساسية رقمية توضح أثر تغير تكلفة البناء وسعر البيع ومدة التنفيذ على العائد السنوي |
| نوع المحتوى | مقال تحليلي + جدول |
| المنصة المناسبة | Telegram + X |
| المصادر المطلوبة | الهيئة العامة للعقار (https://rega.gov.sa/) |
| درجة الأولوية | عالية |
| إمكانية تحويله إلى سلسلة | سلسلة: هندسة بالأرقام |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | خدمة التدقيق المالي واختبار حساسية المشاريع العقارية |
