# E540-134: تقييم العقارات المدرة للدخل بطريقة رسملة الدخل (Income Capitalization): كيف تحسب القيمة العادلة لعمارة تجارية؟

**الوصف المختصر:** تقييم العمائر والمجمعات التجارية بسعر متر الأرض والبناء فقط دون النظر لصافي دخلها السنوي

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | تحليل العرض والطلب ودراسة الجدوى |
| الجمهور المستهدف | المستثمرون، المشترون، الوسطاء العقاريون |
| المشكلة أو السؤال | تقييم العمائر والمجمعات التجارية بسعر متر الأرض والبناء فقط دون النظر لصافي دخلها السنوي |
| القيمة التعليمية أو التجارية | شرح معدل الرسملة (Cap Rate) وصافي الدخل التشغيلي (NOI) لتحديد السعر الاستثماري العادل |
| زاوية المعالجة | مثال تطبيقي لتقييم عمارة تجارية سكنية وحساب قيمتها بناءً على عقود إيجار الموثقة |
| نوع المحتوى | قالب Excel + مقال |
| المنصة المناسبة | Telegram + X |
| المصادر المطلوبة | الهيئة العامة للعقار (https://rega.gov.sa/) |

| إمكانية تحويله إلى سلسلة | سلسلة: هندسة بالأرقام |
