# E540-150: واقع تكلفة بناء العظم والتشطيب في مكة المكرمة (مخططات ولي العهد نموذجاً): تحليل أسعار المواد والمصنعيات

**الوصف المختصر:** اعتماد الملاك على تقديرات تكاليف من مدن أخرى لا تراعي طبيعة تضاريس مكة وتكاليف النقل والخرسانة

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | سلسلة مكة المكرمة ومخططات ولي العهد |
| الجمهور المستهدف | الملاك، المطورون، المقاولون في مكة |
| المشكلة أو السؤال | اعتماد الملاك على تقديرات تكاليف من مدن أخرى لا تراعي طبيعة تضاريس مكة وتكاليف النقل والخرسانة |
| القيمة التعليمية أو التجارية | تقديم نطاقات سعرية واقعية ومؤرخة لتكلفة المتر المربع في مكة مع تفصيل العوامل المؤثرة |
| زاوية المعالجة | تحليل مالي لتكلفة بناء فيلا أو عمارة سكنية في ولي العهد مع التمييز الدقيق بين الأرقام الفعلية والتقديرات |
| نوع المحتوى | تقرير بالأرقام + قالب Excel |
| المنصة المناسبة | Telegram + X + Instagram |
| المصادر المطلوبة | الهيئة السعودية للمقاولين - العقود النموذجية ومؤشرات الأسعار (https://sca.sa/ar/pages/missions) |
| درجة الأولوية | عالية جداً |
| إمكانية تحويله إلى سلسلة | سلسلة: مخططات ولي العهد بمكة (حلقة 5) |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | حاسبة تكلفة البناء المخصصة لمنطقة مكة المكرمة |

## المحتوى

لم يُطوَّر نص هذا الموضوع في المحادثة. المتاح هو بيانات الجدول أعلاه فقط.
