# E540-151: الأراضي داخل حد الحرم وخارج حد الحرم في جنوب مكة: الفروقات التنظيمية والاستثمارية والشرائح المستهدفة

**الوصف المختصر:** عدم التمييز الدقيق لحدود الحرم في مخططات جنوب وغرب مكة وأثر ذلك على التملك والطلب السكني والموسمي

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | سلسلة مكة المكرمة ومخططات ولي العهد |
| الجمهور المستهدف | المستثمرون، المطورون، المشترون، الوسطاء |
| المشكلة أو السؤال | عدم التمييز الدقيق لحدود الحرم في مخططات جنوب وغرب مكة وأثر ذلك على التملك والطلب السكني والموسمي |
| القيمة التعليمية أو التجارية | توضيح خارطة حد الحرم الموثقة في مستكشف مكة الجغرافي وكيف تختلف طبيعة الطلب العقاري على الجانبين |
| زاوية المعالجة | مقارنة استراتيجية بين الاستثمار داخل حد الحرم وخارجه في مشاريع التمليك والإيجار |
| نوع المحتوى | مقال تحليلي + خريطة |
| المنصة المناسبة | Telegram + X + Instagram |
| المصادر المطلوبة | مستكشف مكة الجغرافي - أمانة العاصمة المقدسة (https://maps.holymakkah.gov.sa/) |
| درجة الأولوية | عالية جداً |
| إمكانية تحويله إلى سلسلة | سلسلة: مخططات ولي العهد بمكة (حلقة 6) |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | استشارات اختيار المواقع الاستثمارية في مكة المكرمة |
