# E540-152: تحليل مشاريع شقق التمليك في مخططات ولي العهد: ما هي المساحات والتصاميم والأسعار الأكثر طلباً اليوم؟

**الوصف المختصر:** بناء شقق تمليك بمساحات أو توزيعات داخلية لا تتناسب مع ذائقة وقدرة المشتري المكي

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | سلسلة مكة المكرمة ومخططات ولي العهد |
| الجمهور المستهدف | المطورون العقاريون، المستثمرون في مكة |
| المشكلة أو السؤال | بناء شقق تمليك بمساحات أو توزيعات داخلية لا تتناسب مع ذائقة وقدرة المشتري المكي |
| القيمة التعليمية أو التجارية | دراسة ميدانية للمعروض الحالي من شقق التمليك في ولي العهد (1-4) وتحليل نقاط القوة والضعف فيها |
| زاوية المعالجة | قائمة بالمواصفات الهندسية والمعمارية التي تجعل مشروع التمليك في ولي العهد يتفوق على المنافسين |
| نوع المحتوى | تقرير ميداني + كاروسيل |
| المنصة المناسبة | Telegram + Instagram + Snapchat |
| المصادر المطلوبة | الهيئة العامة للعقار (https://rega.gov.sa/) |
| درجة الأولوية | عالية جداً |
| إمكانية تحويله إلى سلسلة | سلسلة: مخططات ولي العهد بمكة (حلقة 7) |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | خدمة تطوير المنتجات العقارية ومراجعة مخططات شقق التمليك بمكة |

## المحتوى

لم يُطوَّر نص هذا الموضوع في المحادثة. المتاح هو بيانات الجدول أعلاه فقط.
