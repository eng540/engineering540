# E540-157: المكاتب الهندسية في مكة المكرمة: كيف يتعاون المالك مع المكتب الهندسي لاستخراج الرخصة وإغلاق مراحل بلدي؟

**الوصف المختصر:** تأخر إصدار رخص البناء أو تعطل تقارير مراحل التنفيذ بسبب نقص المستندات أو ضعف التواصل مع المكتب

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |

| المشكلة أو السؤال | تأخر إصدار رخص البناء أو تعطل تقارير مراحل التنفيذ بسبب نقص المستندات أو ضعف التواصل مع المكتب |
