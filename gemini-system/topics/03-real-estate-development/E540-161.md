# E540-161: دراسة جدوى تطوير عمارة شقق تمليك في مخطط ولي العهد (نموذج أرقامي تطبيقي خطوة بخطوة)

**الوصف المختصر:** الرغبة في تطوير أرض سكنية إلى شقق تمليك دون وضوح التكلفة الكلية، مدة البيع، وهامش الربح المتوقع

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | سلسلة مكة المكرمة ومخططات ولي العهد |
| الجمهور المستهدف | المطورون العقاريون، المستثمرون، ملاك الأراضي بمكة |
| المشكلة أو السؤال | الرغبة في تطوير أرض سكنية إلى شقق تمليك دون وضوح التكلفة الكلية، مدة البيع، وهامش الربح المتوقع |
| القيمة التعليمية أو التجارية | بناء نموذج مالي افتراضي واقعي (أرض 600م2 - 800م2) يوضح التكاليف والإيرادات ونقطة التعادل |
| زاوية المعالجة | تقرير دراسة جدوى تفصيلي مع التنبيه الصريح بأن الأرقام تقديرية استرشادية قابلة للتغير حسب الموقع والوقت |
| نوع المحتوى | تقرير تحليلي + قالب Excel |
| المنصة المناسبة | Telegram + X |
| المصادر المطلوبة | الهيئة العامة للعقار (https://rega.gov.sa/) |
| درجة الأولوية | عالية جداً |
| إمكانية تحويله إلى سلسلة | سلسلة: مخططات ولي العهد بمكة (حلقة 16) |
| إمكانية تحويله إلى خدمة أو فرصة تجارية | إعداد دراسات الجدوى المخصصة لمشاريع التطوير في مكة |

## المحتوى

لم يُطوَّر نص هذا الموضوع في المحادثة. المتاح هو بيانات الجدول أعلاه فقط.
