# E540-170: المواقف السفلية (البدروم) ومواقف الدور الأرضي (Pilotis) في عمائر مخططات ولي العهد: التصميم الإنشائي والمعماري

**الوصف المختصر:** فقدان مواقف سيارات بسب سوء توزيع الأعمدة مما يعيق إصدار الرخصة أو يقلل جاذبية الشقق للبيع

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | سلسلة مكة المكرمة ومخططات ولي العهد |
| الجمهور المستهدف | المطورون العقاريون، المعماريون، المهندسون الإنشائيون |
| المشكلة أو السؤال | فقدان مواقف سيارات بسب سوء توزيع الأعمدة مما يعيق إصدار الرخصة أو يقلل جاذبية الشقق للبيع |
| القيمة التعليمية أو التجارية | تنسيق شبكة الأعمدة (Column Grid) منذ البداية لتوفير مواقف مريحة ومناورة سهلة للسيارات |
