# E540-174: الخدمات الهندسية المساندة الأكثر طلباً في مخططات ولي العهد (الرفع المساحي، فحص التربة، الإشراف، الفحص)

**الوصف المختصر:** عدم معرفة المهندسين والمكاتب بحجم ونوعية الطلب اليومي من ملاك الأراضي في مخططات جنوب مكة

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الثالث: التطوير العقاري والسوق السعودي (ومخططات ولي العهد بمكة) |
| التصنيف الفرعي | سلسلة مكة المكرمة ومخططات ولي العهد |
| الجمهور المستهدف | المهندسون المستقلون، المكاتب الهندسية، المختبرات |
| المشكلة أو السؤال | عدم معرفة المهندسين والمكاتب بحجم ونوعية الطلب اليومي من ملاك الأراضي في مخططات جنوب مكة |
| القيمة التعليمية أو التجارية | تحليل خريطة الخدمات الهندسية المطلوبة وكيف يبني المهندس أو المكتب باقات خدمية تناسب ملاك المخطط |
| زاوية المعالجة | تقرير فرص مهنية وتجارية للمهندسين والمكاتب في مخططات ولي العهد |

| المنصة المناسبة | Telegram + X |
| المصادر المطلوبة | الأدلة الاسترشادية لكود البناء - الهيئة السعودية للمهندسين (https://www.saudieng.sa/Arabic/RegulationsAndProcedures/Pages/SBCGuidelines.aspx) |
