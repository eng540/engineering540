# E540-265: كيف تبني قاعدة بيانات عملاء وشركاء (CRM) بسيطة وتتابع الفرص التجارية المفتوحة حتى إغلاقها؟

**الوصف المختصر:** نسيان متابعة العملاء الذين استفسروا عن خدمة أو مشروع بسبب الاعتماد على الذاكرة ومحادثات الجوال

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)

## بيانات الموضوع من جدول الاستراتيجية

| الحقل | القيمة |
|---|---|
| المحور | المحور الخامس: الفرص والأعمال والعلاقات المهنية |
| التصنيف الفرعي | بناء العلاقات المهنية وتطوير الأعمال |
| الجمهور المستهدف | المهندسون المستقلون، المقاولون، المطورون |
| المشكلة أو السؤال | نسيان متابعة العملاء الذين استفسروا عن خدمة أو مشروع بسبب الاعتماد على الذاكرة ومحادثات الجوال |
| القيمة التعليمية أو التجارية | تنظيم جدول متابعة العملاء المحتملين (Lead Tracker) وتحديد موعد المتابعة القادم لكل فرصة |
| زاوية المعالجة | قالب Excel/Notion لإدارة علاقات العملاء والفرص الهندسية |
| نوع المحتوى | قالب Excel + مقال |
| المنصة المناسبة | Telegram + X |
| المصادر المطلوبة | الهيئة السعودية للمقاولين - العقود النموذجية ومؤشرات الأسعار (https://sca.sa/ar/pages/missions) |

| إمكانية تحويله إلى سلسلة | سلسلة: المقاول الذكي |
