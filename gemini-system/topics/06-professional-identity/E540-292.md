# E540-292: فن صياغة العقود الشخصية للمهندس المستقل (Freelance/Consultant Engineer): كيف تضمن أتعابك وتحدد نطاق عملك؟

**الوصف المختصر:** تقديم خدمات تصميم أو حصر أو إشراف بالاتفاق الشفهي ثم المماطلة في السداد أو طلب تعديلات لا تنتهي

## الحالة

- الحالة: **فكرة** (القيم المعتمدة: فكرة، مسودة، مراجع، منشور)
- المنصة / تاريخ النشر / الرابط: غير مسجل
- تحقق هندسي مستقل: لم يتم (نُقل المحتوى كما ورد في المحادثة)
